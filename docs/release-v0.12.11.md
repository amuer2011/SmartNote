# v0.12.11 直接导入本地文件夹

安装包：`build/bin/SmartNote-Setup-v0.12.11-direct-import.exe`。免安装版：`build/bin/SmartNote-v0.12.11-direct-import.exe`。

导入按钮移到主窗口右上角，紧挨 Markdown 导出按钮。工作区下拉菜单和工作区设置中的文件夹导入入口已移除，快捷键保持可配置。导入窗口只需选择用户已经准备好的笔记文件夹，不再填写来源、保存位置或新工作区名称。

软件直接使用所选目录，不再另外生成一份笔记库。编辑、删除和自动整理均作用于这个目录。默认选择「保持原目录结构」，关闭该目录的自动整理；也可选择「导入后自动整理」，沿用现有分类和余弦相似度阈值。仍支持进度、停止本次整理、未达阈值保留原位、同名目标保护、图片附件与双链适配。附件适配可能更新所选目录中笔记的本地资源链接，目录内附件与隐藏配置保持原样；不运行 Obsidian 插件。

同一目录再次导入会复用已注册记录及原有任务、附件等元数据，不重复建立记录；本次选择控制该目录自动整理是否启用。首次导入先暂存和验证笔记、附件，再适配笔记引用并注册目录。提交前检查笔记是否被外部修改；注册失败时恢复已适配的笔记，若恢复遇到新的外部修改则保留备份并报告路径。

ZIP 导入与原生备份恢复继续保留在导入窗口的「改用 ZIP 导入」及设置的备份恢复入口，沿用 ZIP 恢复到新目录的流程。

验证覆盖：单文件夹输入、右上角相邻图标、工作区菜单移除入口、目录路径直接使用、保持目录、附件及隐藏配置、重复导入复用、直接语义移动和双链更新、注册失败回滚，以及取消、保存冲突、导入失败、停止整理和模型失败。使用隔离目录与模拟接口，不操作用户实际笔记。截图：[导入窗口](preview-folder-import-v0.12.11.png)、[整理结果](preview-folder-import-result-v0.12.11.png)。
