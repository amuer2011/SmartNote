# v0.12.8 文本块快速复制

安装包：`build/bin/SmartNote-Setup-v0.12.8-block-copy.exe`。免安装版：`build/bin/SmartNote-v0.12.8-block-copy.exe`。

提示块正文、代码块及普通引用块的右上角增加复制图标，鼠标移入或键盘聚焦时显示，使用当前主题样式。点击即可复制，成功时短暂显示对勾，失败时显示重试提示。支持预览、分屏预览以及 AI 回复和审阅中的 Markdown 回复。

提示块复制正文的可读文本，保留列表和表格结构，并排除自身标题、装饰图标、操作按钮及复制反馈。代码块保留其显示文本的缩进、换行和特殊字符。嵌套块可分别复制，操作内层块时优先显示内层按钮。复制不会展开/收起提示块或触发笔记链接，查找也会忽略复制按钮及反馈文字。

验证：

- `markdown-copy.cjs`：悬停/聚焦显示、键盘 Enter/Space、代码缩进与换行、中文和特殊字符、提示块与引用文本、嵌套目标、查找高亮后的复制、反馈及失败重试、重新渲染与过期异步结果、明暗主题及 AI 回复复制通过。
- `admonition-chat.cjs`、`view-navigation.cjs`、`admonition-completion.cjs`：折叠、源行定位、预览/分屏查找与大纲、聊天浮窗/草稿/尺寸恢复、提示补全、快捷键和图谱视图恢复回归通过。

- `editor-attachments.cjs`：附件和图片操作、元数据、工具栏选区及图片窗口回归通过。

复制验证使用隔离数据和模拟剪贴板，不改动用户笔记或实际剪贴板。前端类型检查、生产构建及全量 Go 测试通过。生产程序在独立数据目录启动12秒并正常响应；隔离安装、clean PATH 内置 CPU 推理、卸载和用户数据保留检查通过，用户注册表和快捷方式保持不变。证据见 `.tmp/build-v0128.log`、`.tmp/native-v0128-test.log`、`.tmp/installer-v0128-test.log`；校验值见 [SHA-256](release-v0.12.8-sha256.json)。
