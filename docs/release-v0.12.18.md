# v0.12.18 粘贴与编辑体验

导航“复制”（Ctrl+C / Command+C）仅记录来源，不立即生成副本。在目标目录右键点击紧随“复制”下方的“粘贴”，或按 Ctrl+V / Command+V，才创建副本。在笔记上粘贴使用该笔记所在目录；在目录或工作区根目录上粘贴使用该目录。没有复制来源时禁用粘贴。可连续粘贴，沿用“-副本”“-副本(1)”“-副本(2)”编号，文件和文件夹均支持，不合并或覆盖。范围为当前工作区，切换工作区会清空复制来源。

保留保存冲突保护、独立笔记 ID、原文件不变及目录层级/附件/空目录。跨目录粘贴会调整副本中的本地相对链接：内部文件随复制树定位，外部引用继续指向原目标。准备失败清理临时内容；拒绝把目录粘贴到自身或子目录。编辑器内 Ctrl+C/V 仍执行正文或附件复制粘贴。

逐字输入三个反引号时补全结束围栏。光标留在开头，可输入语言名称，再按 Enter 进入空代码行。支持普通与引用块中的围栏、撤销、Admonition 类型补全；已有代码块内输入不会额外配对，粘贴整段 Markdown 不触发配对，紧邻已有结束围栏时不重复生成。

暗色主题下编辑器绘制的竖线光标及拖放插入位置使用白色，浅色主题保持正文色。CodeMirror 绘制光标时系统原生光标保持透明，避免双重显示。

“面板”菜单的“右侧页签”分组新增“显示全部右侧页签”。全部关闭大纲/关联/AI 聊天，或隐藏整个右侧栏后，均可一键恢复；保留自定义排序与侧栏宽度。空白笔记页面恢复时打开 AI 页签。
