# 知识库助手使用说明

打开笔记右侧的“AI 聊天”。选“工作区”时，助手可以检索和读取这个工作区的笔记，并查询目录、待办、书签、知识关联和附件名称等信息；选“当前笔记”时，只能读取当前笔记和软件通用说明。

可以自然地问：“这个工作区有哪些项目资料？”“结合之前的排查记录，解释这次数据库认证失败可能的原因。”“本周有哪些未完成的循环待办？”“我收藏的数据库资料有哪些？”“这篇笔记引用了哪些笔记，哪些笔记引用了它？”“怎么批量删除循环任务？”助手会按需查资料，并在引用笔记时附可点击的来源。资料不够时可以继续追问，无需每次重新粘贴整篇笔记。

聊天区顶部的时钟图标打开“聊天历史”。发送后自动保存，新建对话保留旧对话，可以搜索标题、继续或删除。重新打开助手会恢复最近对话。历史建议反映当时状态，不能直接覆盖现在的笔记；需要修改时重新提出要求，并核对新生成的差异。

脑形图标打开“工作区长期背景”，适合写项目背景、常用简称、术语和交流偏好，例如“先给结论，引用笔记；把已确认的事实和推测分开”。保存后，在这个工作区的后续主动提问中生效。可随时编辑或清空后保存。模型不会自动把历史聊天里的推测写成长期事实。

笔记是知识来源，聊天是交流记录，长期背景是你主动维护的稳定参考。较长对话保留本地记录，请求使用近期交流；模型通过检索找回需要的笔记，并不会永久记住整个笔记库。笔记删除或变化后，旧引用需要重新核对。

助手了解现有界面和功能，但目前直接写入只支持经过审阅的笔记修改。它可查询任务状态，不能替你完成、改期、删除待办或移动文件；会说明对应入口。附件查询只提供元数据，不表示已读取 PDF、图片等正文。助手不能读取其他工作区、工作区外文件或密钥，也没有终端和联网浏览能力。

聊天和长期背景按工作区保存在应用本地数据目录，可随原生 ZIP 备份导出恢复，普通 Markdown 导出不包含聊天，当前不自动跨设备同步。使用远程模型时，你主动发送的消息、长期背景及本次读取的相关资料会提供给所选供应商；恢复历史、管理背景本身不会发起模型请求。

助手也能按关键词检索以前的交流，用对话标题和更新时间说明出处；不会把历史回复直接当成最新笔记事实。一次最多返回6条片段，覆盖最近200个对话且读取总量最多16MiB。
