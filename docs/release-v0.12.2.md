# v0.12.2 图谱与附件优化

安装包：`build/bin/SmartNote-Setup-v0.12.2-graph-assets.exe`。免安装版：`build/bin/SmartNote-v0.12.2-graph-assets.exe`。

图片按真实像素显示，小图默认不放大，大图适应屏幕；窗口随图片尺寸调整。工具栏可切换原始尺寸和适应窗口，保留滚轮缩放、旋转、拖动、调整窗口、隐藏恢复、下载与空白关闭。

知识拓扑仅呈现笔记链接和手动关联，移除语义推荐、相似度门槛与项目/标签推断连线。点“手动连线”后依次点击两篇笔记，再保存关联；也可打开“关联与备注”选择笔记。单击节点或连线可编辑备注，双击节点打开笔记。默认关闭右侧关联面板，需要编辑时再展开。节点及关系备注单独存放，支持清空、原生备份恢复和 WebDAV 同步；保存备注不会改写笔记正文，也不重排拓扑。

附件库支持仅查看未引用附件、清理全部未引用附件、单个删除、全选和批量删除。删除前保存当前笔记，并在后端重新检查工作区和回收站引用。默认跳过仍被引用的附件；明确勾选后才允许删除这些附件，相关链接会失效。删除操作清理本地原件和记录，不删除图床文件；删除状态参与同步，防止旧设备重新带回记录。重新导入相同内容使用新附件身份。多设备请使用此版本或更新版本，以识别附件删除记录。

embedding 模型维持固定内置 BAAI/bge-small-zh-v1.5；已取消模型更换功能，没有新增对应设置。
