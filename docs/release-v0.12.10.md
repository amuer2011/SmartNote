# v0.12.10 文件夹导入与可选整理

安装包：`build/bin/SmartNote-Setup-v0.12.10-folder-import.exe`。免安装版：`build/bin/SmartNote-v0.12.10-folder-import.exe`。

从顶部工作区菜单右上角的导入图标，或「设置 → 工作区与备份 → 导入笔记文件夹」进入。选择来源文件夹、新工作区的保存位置和名称，然后选择整理方式：

- **保持原目录结构（默认）**：复制笔记、附件和空目录，关闭新工作区自动整理；后续打开、编辑笔记也不会因自动分类改变目录。
- **导入后自动整理**：启用新工作区自动整理，使用内置语义模型逐篇分类。显示进度及已移动、保持原位、失败数量，可停止后续整理；已经复制的笔记仍然保留。未达阈值保留原位，同名目标不覆盖。

两种方式均复制为独立工作区，不修改来源文件夹。分类、描述和余弦相似度阈值沿用当前工作区，旧工作区的目录学习样本不迁移；没有当前工作区时使用默认分类。保存冲突会阻止开始导入；取消选择或复制失败保留原工作区。ZIP 导入和备份恢复仍可使用，切换沿用工作区保存及快照隔离机制。

支持 UTF-8 `.md`、YAML 属性、笔记双链、相对路径和 Obsidian 库内资源。附件保留在原目录，同时加入附件库；笔记中的本地资源引用转换为附件库链接，自动整理移动笔记后图片仍可访问。库内资源先按相对路径、再按库根路径、最后按唯一文件名或路径后缀解析；缺失、歧义和无法解析的链接保留原文并显示提示。自动移动使用已有归档流程更新笔记链接。

隐藏配置目录（如 `.obsidian`、`.git`）及符号链接不导入，不运行 Obsidian 插件。Markdown 扩展的渲染范围沿用 SmartNote 已有能力。单次最多 20,000 个文件、总计 2 GB；单篇笔记最多 32 MB，单个附件最多 100 MB。非 UTF-8 笔记、重复笔记 ID、已存在目标目录等情况报错，不覆盖目标文件。

验证范围：

- 后端文件导入：原始字节不变、目录及空目录、BOM、中文路径、自定义属性、附件去重、时间戳、分类配置及学习样本、双链和移动后反向链接；无效目标、重复 ID、编码错误、库外资源与错误链接。
- 前端 `folder-import.cjs`：默认方式、目录选择与取消、失败保留旧工作区、导入成功、逐篇刷新哈希、同名冲突继续、停止整理、模型失败停止、保存冲突阻止导入和 ZIP 兼容入口。
- `workspace-switcher.cjs`、`view-navigation.cjs`、`editor-attachments.cjs`：工作区切换、视图和附件相关回归。
