# v0.12.12 批量忽略待办识别

此项功能随 [v0.12.13](release-v0.12.13.md) 一并交付，未单独发布 v0.12.12 安装包。

在待办识别确认窗口中，紧挨「忽略此笔记」增加「忽略所有」。点击后，对当前工作区全部待确认笔记执行与「忽略此笔记」相同的操作，包括之前选择「稍后确认」的结果：以后不再自动识别待办或自动分类，可通过笔记右键菜单单独恢复。已确认待办、手动 Markdown 任务、笔记正文和其他工作区不受影响；以后新识别的笔记仍会正常提示。窗口说明与按钮悬停提示会显示作用范围及数量，沿用当前主题样式。

批量请求先保存当前笔记，再检查当前工作区以及所有待确认结果的版本与状态，一次写入元数据。保存冲突、版本过期、任务缺失或已确认时拒绝整个请求，不写入部分结果。处理期间禁用操作；失败后刷新当前工作区并显示错误，其他工作区不接收迟到的错误提示。

验证：`TestIgnoreAllPendingTaskIntents` 和 `TestIgnoreAllTaskIntentsWorkspaceAndEmptySelection` 覆盖版本/状态/缺失结果校验、重复引用、持久化、正文保持、已加入和手动任务保留、编辑后仍忽略、独立恢复与工作区隔离；原有单篇忽略和待办确认测试回归。`intent-ignore-all.cjs` 覆盖按钮相邻、待确认数量、暂缓队列、失败/保存冲突/重试、禁用状态、未来识别和跨工作区迟到错误。测试使用隔离目录及模拟接口。

界面见 [预览](preview-intent-ignore-all-v0.12.12.png)。
