# v0.12.14 多标签、右侧页签与聊天附件

安装包：`build/bin/SmartNote-Setup-v0.12.14-note-tabs.exe`。免安装版：`build/bin/SmartNote-v0.12.14-note-tabs.exe`。

笔记现在支持同时打开多个水平标签页，同一篇笔记再次打开会激活已有页签。每个页签可关闭，`+` 打开空白新标签页，提供新建、快速打开和导入笔记入口。默认快捷键：Ctrl/Command+T 新标签页，Ctrl/Command+W 关闭，Ctrl/Command+Tab 和 Ctrl/Command+Shift+Tab 切换；可在快捷键设置中修改。切换与关闭先保存，遇到未解决的冲突会保留当前笔记及草稿。支持鼠标中键关闭、标题提示和标签栏横向滚动。

标签跟随笔记身份及当前文件名，切换工作区会清空旧工作区页签。继续保留启动恢复上次打开笔记的行为，暂不恢复整组页签；主动切到空白页且退出后保持空白。文件导航只隐藏笔记名称末尾的 `.md`（大小写均支持），实际路径、重命名及链接不受影响，同名后缀的文件夹保留原名。

右侧页签默认按「大纲、关联、AI 聊天」排列，可拖动调整顺序，也可单独关闭。从顶部「面板 → 右侧页签」重新打开；排序和关闭状态保存在界面设置中。全部关闭时释放右侧空间，「恢复默认布局」恢复默认顺序及显示。支持方向键、Home、End 切换。

AI 聊天支持选择文件、粘贴图片/文件和拖入文件；粘贴至少2000字的文本自动转为 `.txt` 附件，直接输入的长消息在发送时同样转换。发送前显示文件卡片和图片缩略图，可移除附件；消息中保留附件卡片。每条消息最多8个附件，单文件8MB、合计16MB，对话整体保留容量保护，超出后提示新建对话。

附件字节和聊天消息保存在同一个对话记录内，不进入笔记附件库，也不会改写原始文件。恢复聊天历史时附件随对话恢复；删除对话会连同附件原子删除，不产生独立附件残留。未发送的附件只留在当前对话输入区，切换或新建对话时清除。工作区之间隔离。聊天历史检索不会读取其他对话附件正文。

文本/Markdown/代码/CSV及常见文本配置在本机解码；DOCX、XLSX、PPTX提取可读正文（不解析图片、公式计算或复杂排版）。长附件每份提供前32000字并附截断提示。PNG/JPEG/GIF/WebP按图片传给所选模型；OpenAI兼容服务的其他文件（包括PDF）使用文件内容消息，是否接受和识别取决于具体服务及模型。Ollama使用原生图片消息，不支持直接读取的二进制文件会明确提示转换为文本或图片。识别能力不包含本机OCR。

验证覆盖多笔记去重、空白页、切换/关闭/快捷键、冲突保留、隐藏后缀、右侧页签拖动/恢复、长文本/图片/PDF请求、聊天删除和工作区隔离。后端集成测试验证真实HTTP请求体、文本和Word提取、附件校验、跨重启保存及删除后无附件库残留。原有会话恢复、视图、工作区及忽略所有流程回归通过。
