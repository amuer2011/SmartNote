# v0.12.5 拓扑笔记打开修复

安装包：`build/bin/SmartNote-Setup-v0.12.5-graph-open.exe`。免安装版：`build/bin/SmartNote-v0.12.5-graph-open.exe`。

修复拓扑标题文字区域不响应点击，以及密集布局中原生备注文字覆盖圆点时拦截节点操作的问题。点击命中备注时，优先检查鼠标位置是否落在真实笔记圆点内；若命中圆点，操作对应笔记，备注自身仍可在文字区域编辑。

双击节点圆点或标题打开原笔记。单击选中后，可按 Enter 或点击画布左下角“打开笔记”。空格仍在图上编辑备注；双击节点备注或连线备注进入备注编辑，手动连线期间不打开笔记。操作按钮与输入区域的键盘事件不重复触发打开。

鼠标双击使用真实 MouseEvent.detail，避免图形引擎在隐藏/显示画布后保留的点击计时，将新单击误判为双击或漏判真正双击。触摸双击沿用既有入口。

验证：

- 先以真实鼠标复现标题区域双击无效，以及备注覆盖圆点时无法打开笔记；修复后二者均通过。
- 真实鼠标双击圆点、标题，单击标题后空格编辑及 Enter 打开，按钮打开均定位到正确笔记；快速关闭/重开后的单击仍保持选中行为。
- 真实鼠标双击节点备注和连线备注仍进入对应备注编辑，手动连线时 Enter 不打开笔记。此前备注保存失败保留草稿、清空、长文本、明暗主题、同步拖动与缩放、布局及正文不变等图谱回归通过。
- 既有布局持久化与按范围恢复回归通过。

验证使用隔离数据及模拟服务，未操作用户笔记、配置或真实模型服务。

前端类型检查、生产构建、全量 Go 测试通过。生产程序在独立数据目录启动12秒并正常响应；隔离安装/卸载、clean PATH 内置 CPU 推理、用户数据保留、真实用户注册表及快捷方式不变验证通过。安装证据见 `.tmp/installer-v0125-test.log`；校验值见 [SHA-256](release-v0.12.5-sha256.json)。
