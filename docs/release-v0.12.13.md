# v0.12.13 启动恢复笔记

安装包：`build/bin/SmartNote-Setup-v0.12.13-session-restore.exe`。免安装版：`build/bin/SmartNote-v0.12.13-session-restore.exe`。

每次启动自动恢复当前工作区上次打开的笔记。按应用数据目录和工作区分别保存笔记 ID 及路径，优先通过 ID 重新定位，必要时按保存路径匹配当前工作区笔记；重命名或移动后更新记录。恢复沿用普通打开笔记的流程，保留现有默认预览视图、草稿恢复及磁盘修改冲突保护。

主动关闭笔记页会清除该工作区的恢复记录，下一次启动保持关闭；笔记不存在时清理记录并正常进入主界面。启动期间用户已经手动打开其他笔记或切换工作区时，恢复过程不会覆盖用户选择。此记录存放在本机 WebView2 持久存储中，不写入笔记正文；存储损坏或不可用时仍可正常打开、编辑笔记。工作区切换本身保持现有行为，启动时才执行自动恢复。

本版同时交付 [批量忽略待办识别](release-v0.12.12.md)：在「忽略此笔记」旁增加「忽略所有」，针对当前工作区全部待确认笔记执行持久忽略，可通过笔记右键菜单逐篇恢复，已加入的待办及手动任务不受影响。

验证：`note-session.cjs` 使用同一持久浏览器上下文的全新页面模拟退出和再次启动，覆盖恢复、工作区与数据目录隔离、移动后的 ID 定位、路径回退、主动关闭、删除、默认预览、草稿冲突、慢启动时手动选择及损坏存储。`intent-ignore-all.cjs` 验证批量忽略；`workspace-switcher.cjs`、`view-navigation.cjs` 回归相关工作区及视图行为。测试使用模拟接口和隔离目录，不修改用户实际笔记。

界面：[恢复笔记](preview-note-session-v0.12.13.png)、[忽略所有](preview-intent-ignore-all-v0.12.12.png)。

前端类型检查、生产构建及全量 Go 测试通过，包括批量忽略的后端集成测试。最终程序在独立数据目录启动12秒响应正常；隔离安装、clean PATH 下内置 CPU 模型推理、卸载及用户数据保留验证通过，用户注册表和快捷方式不变。安装验证目录：`D:\CHANG\SmartNote-release-stage\installer-v091-41dd78d3`。
