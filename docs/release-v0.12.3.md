# v0.12.3 图上备注与图片全屏

安装包：`build/bin/SmartNote-Setup-v0.12.3-inline-graph.exe`。免安装版：`build/bin/SmartNote-v0.12.3-inline-graph.exe`。

知识拓扑中，单击选中节点或连线后按空格，在图上直接编辑备注。Enter 保存、Shift+Enter 换行、Esc 取消；输入法选字不触发保存。也可双击已显示的备注进入编辑。失败时保留草稿，清空后保存可移除备注。备注仍独立保存，沿用版本冲突检查及既有备份、同步能力，不改笔记正文。

笔记标题改为14px粗体，随主题切换深浅；备注采用12px暖色文字与独立标记。备注在屏幕坐标中排版，避让节点标题、其他备注及布局按钮，必要时用虚线标明归属。拖动、缩放后跟随更新，保存不重排拓扑、不改变当前视口。长备注显示最多四行摘要，悬停可看全文，编辑保留完整内容。密集图的有限空间可能无法容纳全部长备注，可放大或拖动节点查看。

右侧面板只用于手动关联的创建、删除，不再编辑备注；单击节点或连线不会自动展开右侧面板。双击节点仍打开笔记。

图片工具栏增加全屏/恢复按钮，铺满当前应用窗口；再次点击或按 Esc 恢复原窗口大小，再按 Esc 关闭。保留真实尺寸、适应窗口、缩放、旋转、拖动、下载、隐藏恢复、手动调整窗口和空白关闭。全屏时小图仍不自动放大。
