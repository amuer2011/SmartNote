# v0.12.15 模型选择与思考强度

安装包：`build/bin/SmartNote-Setup-v0.12.15-model-menu.exe`。免安装版：`build/bin/SmartNote-v0.12.15-model-menu.exe`。

AI 聊天底部的模型选择改为紧凑按钮，浮层按供应商分组展示已启用模型，当前选择有勾选与主题高亮。可搜索供应商或模型，列表独立滚动，长模型名显示省略号并提供完整名称提示。浮层自动避让屏幕边缘，适配浅色、深色主题，也可在浮动聊天窗口中使用。

思考强度整合到模型浮层底部，使用带刻度的离散滑杆和当前档位标记；模型列表滚动时底部控制区保持可见。聊天底部的强度按钮也可直接打开该控制区。供应商设置页采用相同滑杆。滑杆使用已有的模型能力规则，不添加模型不支持的档位；Ollama 仍读取实际模型元数据，加载期间暂停发送，忽略旧模型迟到结果。模型默认对应不发送思考参数，DeepSeek 的 `none` 继续使用已有关闭思考参数适配。

支持上下方向键、Enter 选择模型，Escape 关闭并返回触发按钮；滑杆支持方向键、Home、End。点击浮层外关闭，搜索框不会触发笔记界面的同类按键。切换模型和强度不清空聊天草稿或历史，也不会自动发送消息。笔记修改仍沿用现有审阅确认流程。

本包包含 [v0.12.14](release-v0.12.14.md) 的笔记多标签、导航隐藏后缀、右侧页签排序与关闭恢复、聊天文本/图片/文件附件及会话删除清理。
