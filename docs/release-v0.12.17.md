# v0.12.17 副本与剪贴板

文件和标签右键菜单与鼠标留出10px间距，测量实际尺寸后显示，靠近屏幕边缘时换边并保持在屏幕内。

标签右键支持“全部关闭”“关闭其他”“关闭右侧全部”，按被右键的标签操作，右键本身不会切换笔记。无其他标签或右侧无标签时禁用对应菜单项。全部关闭后保留一个空白标签。支持键盘菜单、方向键和 Escape，保存冲突时中止批量关闭并保留草稿。

导航移除剪切及粘贴移动菜单和快捷键，增加“复制”（默认 Ctrl+C，Mac 为 Command+C，可在快捷键设置修改）。复制直接在同目录创建副本：`名称-副本.md`、`名称-副本(1).md`、`名称-副本(2).md`，文件夹遵循相同规则。复制已有副本沿用编号，不叠加“-副本”。跳过占用名称，不合并或覆盖。目录复制保留层级、空目录、附件及 Markdown 正文；为每篇复制笔记生成独立 ID，保留原文件不变。拒绝工作区外路径、回收站根目录和符号链接；准备失败不留下半份副本。

编辑器粘贴普通文件、文件图片、带网页 HTML/URL 来源的图片时使用本地附件链接。只有无来源信息的原始剪贴板截图按 PicGo 配置上传；关闭 PicGo 或上传失败时保存本地。Windows 额外检查原生文件剪贴板格式，避免将名为 `image.png` 的真实文件误判为截图。浏览器没有截图来源标记时，按剪贴板格式和通用图片名称识别；无法判断来源时保守保存在本地。文件选择和拖入继续保存本地，多附件按顺序导入。AI 聊天附件仍随会话存放，不进入图床流程。

安装包：`build/bin/SmartNote-Setup-v0.12.17-copy-clipboard.exe`。免安装版：`build/bin/SmartNote-v0.12.17-copy-clipboard.exe`。

验证通过：新增 `TestCopy*` 覆盖重复命名、复制副本、跨文件/文件夹名称冲突、独立笔记 ID、原文不变、层级/附件/空目录、CRLF 正文保留、非法路径和失败清理。`context-copy-clipboard.cjs` 覆盖标签批量关闭及保存冲突、文件与标签菜单键盘焦点/操作、鼠标间距和边缘位置、复制菜单与快捷键、编号，以及模拟剪贴板的文件/图片/网页图片/截图分流和多文件顺序导入。`note-tabs-chat-attachments.cjs`、`navigation-search.cjs` 回归通过。
