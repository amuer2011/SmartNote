## v0.2 数据与可靠性

- 单篇移动先保存原文与操作日志，再排他创建目标文件、更新关联链接、移除原文件。目标存在或内容冲突时不覆盖。
- 原文和 `journal.json` 保存在应用数据 `workspaces/<ID>/operations/<操作ID>/`。启动检查未提交日志并尝试回滚；回滚发现外部修改会保留文件并报错，需根据恢复副本人工处理。
- 外部笔记原本无 Front Matter ID 时，明确移动操作会添加原索引 ID，防止笔记与任务身份因路径变化丢失。普通扫描不改写用户正文。
- 链接重写支持常见单行内联链接、引用定义、双链及标签别名，跳过 YAML、围栏/行内代码。不是覆盖所有 CommonMark 语法的完整解析器。
- 附件导入支持尖括号空格路径、转义/平衡括号、引用式图片、相对路径 Obsidian 图片嵌入。同内容附件去重，未引用文件也保存在独立附件库。
- Todo 扩展属性以 `tasks-metadata.json` 持久化；复选框状态仍以 Markdown 为准。首次设置详情或切换显式任务状态时添加稳定 task 注释。
- 日期支持 `YYYY-MM-DD` 和今天/明天/后天；相对日期优先基于笔记创建时间，缺少创建时间则基于文件修改时间。手动设置日期可覆盖或清除推断日期。
- FTS 通过独立指纹表跳过未修改项，并清理删除项；首次升级旧索引自动重建。SQLite 可删除后重建，不承载正文权威数据。
- 外部修改仍采用 3 秒扫描，暂未引入 fsnotify、持久化后台队列或万篇性能保障。

### 智能整理诊断说明

语义建议分别列出第一、第二名分类及得分、领先差值计算式、两项阈值的达标情况。相似度不足时建议补充正文、完善分类描述或新增分类；差值不足时建议区分前两名分类的收录范围。用户确认分类正确后，可参考展示的门槛值调整，数值向下保留四位小数，避免显示舍入导致照填后仍不达标。仅启用一个分类时明确说明没有第二名并跳过差值检查。两项同时失败时分别展示原因，原目录保持不变。

智能整理面板每次打开重新读取当前工作区语义配置，展示已保存的相似度和差值门槛；设置保存后通知打开的面板重新分析。关闭面板时使进行中的请求失效。分类名称、得分、门槛、失败原因关键词与调整建议重点使用红色加粗和浅红背景，并适配深色主题。所有内容使用 Vue 文本绑定。
