# v0.12.4 拓扑备注与窗口拖动

安装包：`build/bin/SmartNote-Setup-v0.12.4-canvas-drag.exe`。免安装版：`build/bin/SmartNote-v0.12.4-canvas-drag.exe`。

拓扑备注改为图形引擎内的原生元素，和拓扑共用渲染器、坐标变换及绘制帧。移除此前单独更新的 HTML 备注层及引导线，不再显示“笔记备注/连线备注”类型标签。拖动节点时同步更新该笔记及相连边的备注，平移和缩放直接使用图形引擎的坐标变换，避免单独排版导致的滞后。

连线备注位于连线中点，文字使用与主题一致的不透明衬底，并绘制在线条之上，线条不会穿过文字。笔记备注位于标题下方，以暖色普通字重区别于加粗标题。长备注显示四行摘要，悬停可查看全文；选中后空格编辑，Enter 保存、Shift+Enter 换行、Esc 取消。点击备注仍选中原节点或连线。备注数据、正文和布局保存格式沿用既有实现，辅助绘制元素不会作为笔记坐标保存。密集图仍可拖动节点或放大，以展开较长文字。

图片预览窗口支持按住顶部工具栏的非按钮区域拖动。按钮正常执行原操作，图片区域仍用于平移图片；拖动、调整大小及应用窗口变小时，窗口保持在可见范围内。全屏时不可拖动，退出全屏恢复原窗口大小和位置，保留缩放、旋转、隐藏恢复、下载和空白关闭。
