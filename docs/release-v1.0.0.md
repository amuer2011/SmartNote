# v1.0.0

SmartNote 首个正式版本：本地 Markdown 笔记、离线智能整理与个人知识库。

## 下载

| 文件 | 用途 |
| --- | --- |
| `SmartNote-Setup-v1.0.0-windows-x64.exe` | Windows 安装包，安装到当前用户目录，创建桌面与开始菜单入口。 |
| `SmartNote-v1.0.0-windows-x64.exe` | 免安装版，下载后直接运行。 |
| `SHA256SUMS.txt` | 两个程序的 SHA-256 校验值。 |

系统要求：Windows 10 / 11 x64，Microsoft Edge WebView2 Runtime。安装包与免安装版均包含中文语义模型和 CPU 运行库，核心离线能力无需额外配置模型、Python、Ollama 或显卡。

## 功能特点

- **本地 Markdown**：多工作区、多笔记标签、编辑 / 预览 / 分屏、自动保存、草稿恢复、查找替换与正则表达式。
- **离线智能**：内置 BGE 中文模型，支持长文语义检索、关键词搜索、自定义分类与自动归档。
- **待办与日历**：待办意图确认、相对日期、循环与截止日期、当日 / 最近待办、农历节气、节假日与调休本地缓存；任务结束后按年月归档源笔记。
- **知识关联**：本地引用、大纲、整篇收藏、位置书签和知识拓扑；支持手动关联、节点及连线备注、布局保存。
- **可选 AI**：OpenAI 兼容接口或本机 Ollama，多供应商与模型、适配模型的思考强度、工作区检索读取、来源引用、会话附件和交互式修改建议；确认差异后写回。
- **数据迁移与同步**：文件夹与 Markdown ZIP 导入导出、原生备份、WebDAV 双向同步 / 上传备份、冲突比较与手动合并。
- **文件与附件**：目录拖动、复制后粘贴、副本编号、回收站、附件库；普通文件和图片本地保存，剪贴板截图可按配置使用 PicGo。
- **界面定制**：深浅主题、独立字体字号、可编辑快捷键、自由调整与隐藏面板、右侧页签排序及恢复。

本版统一应用界面、Windows 文件属性与安装器的版本号，增加 GitHub Actions 自动构建和标签发布。构建会执行前端类型检查、生产打包、Go 测试，以及隔离安装、离线模型推理、卸载与用户数据保留检查；通过后生成发布包与校验文件。

## 使用提示与当前范围

打开有读写权限的本地目录作为工作区即可开始。现有用户继续使用原工作区与应用数据；卸载程序保留用户数据，重要笔记建议先做备份。

当前发布面向 Windows x64。macOS / Linux 安装、自动更新、退出后的系统提醒，以及大规模性能和真实服务长期兼容性仍需完善。Obsidian 导入支持常见 Markdown 和引用方式，不保证第三方插件完全兼容。

详细使用、截图和构建说明见 [README](https://github.com/amuer2011/SmartNote#readme)，同步与 AI 配置见 [配置指南](https://github.com/amuer2011/SmartNote/blob/v1.0.0/docs/sync-and-llm.md)。
