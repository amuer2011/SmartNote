## UI 检查复现

完成前端构建后，在两个终端分别运行：

```powershell
# 终端一，在项目根目录
node frontend/node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 4173 frontend
```

```powershell
# 终端二，在项目根目录
node frontend/tests/ui-smoke.cjs
```

Windows 默认使用 `C:/Program Files/Google/Chrome/Application/chrome.exe`。其他安装路径可通过 `CHROME_PATH` 指定；非 Windows 可先执行 `npx playwright install chromium` 安装浏览器。用 `SMARTNOTE_TEST_URL` 覆盖测试地址。
